📋 المتطلبات:
-----------
✓ PHP 7.4+
✓ MySQL 5.7+
✓ Apache مع mod_rewrite

🚀 خطوات التثبيت:
----------------

1. رفع الملفات:
   - ارفع جميع الملفات إلى الخادم

2. إنشاء قاعدة البيانات:
   - افتح phpMyAdmin
   - استورد ملف database.sql

3. تعديل الإعدادات:
   - افتح: config/database.php
   - عدل معلومات الاتصال بقاعدة البيانات

4. ضبط الصلاحيات:
   chmod -R 755 uploads/

5. الوصول للنظام:
   http://yourdomain.com/
